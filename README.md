## Proyectos

### Herramientas e IA

**[tomd](https://github.com/apnauj/tomd)** — Conversor de documentos a Markdown desde la
terminal: PDF, Office, imágenes y audio. CLI, interfaz web y caché en disco, con tipado
estricto y CI que exige 85% de cobertura.

**[InvertekAgent](https://github.com/apnauj/InvertekAgent)** — Agente conversacional que
responde dudas técnicas sobre variadores Invertek Optidrive E3 usando únicamente
documentación oficial, sin inventar respuestas. Hackathon ReshapeX, con el equipo
*aigents*.

### Backend y nube

**[TruequeU](https://github.com/apnauj/TruequeU)** — API REST en .NET 10 para una
plataforma de trueque: autenticación JWT, arquitectura por capas y siete controladores de
dominio. El front en React está en
[TruequeU-Front](https://github.com/apnauj/TruequeU-Front).

**[fastapi-aws](https://github.com/apnauj/fastapi-aws)** — La misma API FastAPI desplegada
en AWS de dos formas distintas: contenedor sobre Lambda vía ECR y Mangum, y servicio en
EC2 con Docker, systemd y S3 con URLs prefirmadas.

### Fundamentos

**[The Feline Graph Chronicles](https://github.com/apnauj/TheFelineGraphChronicles)** —
Seis algoritmos de grafos implementados desde cero, sin librerías, y dibujados paso a paso
en una interfaz JavaFX. 58 pruebas JUnit.

**[DiscoBallPlayer](https://github.com/apnauj/DiscoBallPlayer)** — Reproductor de música
donde cada modo de reproducción se apoya en una estructura de datos escrita a mano: un BST
para el orden alfabético, una lista circular doble para aleatorio, una cola para llegada.
