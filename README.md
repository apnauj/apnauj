## 🔨 What I've been building

<details>
<summary><b>🛠️ tomd</b> — turns PDFs, Office files, images and audio into Markdown, from the terminal</summary>

<br>

A CLI, a small web UI and a disk cache around document conversion. Strict typing
(`py.typed`), a full test suite, and CI running `ruff`, `mypy` and `pytest` across
Python 3.11 and 3.12 with an 85% coverage gate.

`Python` · `uv` · `pytest` · `mypy`

**[→ Repository](https://github.com/apnauj/tomd)**

</details>

<details>
<summary><b>🤖 InvertekAgent</b> — a conversational agent that never makes up a technical answer</summary>

<br>

Answers technical questions about Invertek Optidrive E3 variable frequency drives using
**only** official documentation — every answer is grounded in a real file on disk. Built at
the ReshapeX Agent Sprint Hackathon with team *aigents*.

`Python` · `Streamlit` · `RAG` · `LLM`

**[→ Repository](https://github.com/apnauj/InvertekAgent)**

</details>

<details>
<summary><b>🐈 The Feline Graph Chronicles</b> — six graph algorithms written from scratch, drawn step by step</summary>

<br>

BFS, DFS, Dijkstra, Bellman-Ford, Floyd-Warshall and Kruskal — no graph libraries, all
implemented by hand and visualized move by move in a comic-styled JavaFX interface.
58 JUnit tests.

`Java` · `JavaFX` · `Maven` · `JUnit 5`

**[→ Repository](https://github.com/apnauj/TheFelineGraphChronicles)**

</details>

<details>
<summary><b>🔁 TruequeU</b> — a bartering platform where students swap things they no longer use</summary>

<br>

REST API in .NET 10: JWT in an `HttpOnly` cookie, layered architecture, seven domain
controllers, moderation and reporting. The React client lives in
[TruequeU-Front](https://github.com/apnauj/TruequeU-Front).

`C#` · `ASP.NET Core` · `EF Core` · `SQL Server`

**[→ Repository](https://github.com/apnauj/TruequeU)**

</details>

<details>
<summary><b>🪩 DiscoBallPlayer</b> — a music player where the data structure *is* the feature</summary>

<br>

Each playback mode is backed by a different hand-written structure: a BST for alphabetical
order, a doubly circular linked list for shuffle, a queue for arrival order. Not a single
`java.util` collection is used as a playback structure — that was the whole point.

`Java` · `JavaFX` · `Maven` · `JUnit 5`

**[→ Repository](https://github.com/apnauj/DiscoBallPlayer)**

</details>

<details>
<summary><b>☁️ fastapi-aws</b> — the same API deployed to AWS two different ways</summary>

<br>

One question, two answers: a container running on **Lambda** through ECR and Mangum, and a
service on **EC2** with Docker, systemd and S3 pre-signed URLs. The README compares the
trade-offs side by side.

`Python` · `FastAPI` · `AWS` · `Docker` · `boto3`

**[→ Repository](https://github.com/apnauj/fastapi-aws)**

</details>
